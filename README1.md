# ระบบประเมินพนักงาน LINE OA (กันปั้มดาว + เก็บข้อมูล + สวยงาม)

ระบบนี้ให้ลูกค้าให้ดาว (1–5) และเขียนความคิดเห็นเกี่ยวกับพนักงาน โดยเก็บข้อมูลลง **Google Sheet** ฟรี
และมีระบบ **ป้องกันการปั้มดาว (anti-fraud)** หลายชั้น พร้อมหน้า **Admin + Dashboard** ดูสถิติแบบสวยงาม

ไฟล์ในชุดนี้
- `Code.gs` — โค้ดหลังบ้าน (Google Apps Script) เก็บข้อมูล + ตรรกะกันโกง
- `eval.html` — หน้าให้ลูกค้าประเมิน (เปิดใน LINE / มือถือ)
- `admin.html` — หน้าผู้ดูแล: สร้างลิงก์/QR + ดู Dashboard
- `README.md` — คู่มือนี้

---

## ภาพรวมการทำงาน

1. แอดมินเปิด `admin.html` → ใส่ชื่อพนักงาน → กดสร้างลิงก์ (ได้ลิงก์ + QR)
2. ส่งลิงก์/QR ให้ลูกค้า (แปะใบเสร็จ, ส่งใน LINE, ตั้งเป็น Rich Menu ฯลฯ)
3. ลูกค้าเปิด `eval.html` → ให้ดาว + ความเห็น → กดส่ง
4. ข้อมูลเข้า Google Sheet ทันที → ดูสรุปได้ในแท็บ Dashboard ของ `admin.html`

---

## วิธีกันปั้มดาว (ทำงานอย่างไร)

เนื่องจากเลือก **ไม่ใช้ LINE Login** ระบบจึงป้องกันด้วยหลายชั้นรวมกัน:

| ชั้น | กันอะไร |
|---|---|
| **ลิงก์ใช้ครั้งเดียว (Token)** | กันดีที่สุด — 1 ลิงก์/QR ใช้ประเมินได้ครั้งเดียว ใช้แล้วลิงก์ตาย พนักงานปั้มเองไม่ได้เพราะต้องให้แอดมินสร้างลิงก์ (และทุกครั้งถูกบันทึก) |
| **อายุลิงก์** | ลิงก์หมดอายุอัตโนมัติ (ค่าเริ่มต้น 48 ชม.) |
| **Nonce (ตั๋วครั้งเดียว)** | ต้องเปิดหน้าจริงก่อนถึงส่งได้ กันสคริปต์ยิงตรงเข้า API และกันการกดส่งซ้ำ |
| **เวลาบนหน้า** | ส่งเร็วเกิน (เช่น <3 วินาที) ถือว่าเป็นบอท → ปฏิเสธ |
| **Honeypot** | ช่องซ่อนดักบอท ถ้ามีค่าจะถูกทิ้งเงียบ ๆ |
| **ลายนิ้วมืออุปกรณ์** | โหมดลิงก์เปิด: เครื่องเดิมประเมินซ้ำในวันเดียวจะถูกบล็อก/ติดธง |
| **ติดธงผิดปกติ** | ถ้าพนักงานได้รับการประเมินถี่ผิดปกติต่อวัน จะถูกทำเครื่องหมายให้ตรวจสอบใน Dashboard |

> 💡 **แนะนำ:** ใช้ "ลิงก์ใช้ครั้งเดียว" (token) เป็นหลัก — เป็นวิธีกันปั้มที่แข็งแรงที่สุดเมื่อไม่มี LINE Login
> ถ้าต้องการความปลอดภัยสูงสุดในอนาคต ค่อยเพิ่ม LINE Login (LIFF) เพื่อผูก 1 บัญชี LINE = 1 การประเมิน

## ติดตั้ง (ครั้งเดียว ~10 นาที)

### 1) สร้าง Google Sheet + วางโค้ด
1. ไปที่ [sheets.new](https://sheets.new) สร้างไฟล์เปล่า ตั้งชื่อตามใจ
2. เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิมทิ้ง แล้ววางเนื้อหาจาก `Code.gs` ทั้งหมด
4. แก้ค่าในส่วน `CONFIG` ด้านบนสุด — **อย่างน้อยต้องเปลี่ยน** `ADMIN_KEY` ให้เป็นรหัสลับของคุณ
5. กด **Save** (รูปแผ่นดิสก์)

### 2) สร้างตาราง
1. ที่แถบฟังก์ชันด้านบน เลือก `setup` แล้วกด **Run**
2. ครั้งแรกจะให้อนุญาตสิทธิ์ → Review permissions → เลือกบัญชี → Advanced → Go to … (unsafe ก็กดต่อได้ เพราะเป็นสคริปต์ของคุณเอง) → Allow
3. กลับมาดู Google Sheet จะมีแท็บ `Ratings` และ `Tokens` ปรากฏขึ้น

### 3) Deploy เป็น Web App
1. มุมขวาบน **Deploy → New deployment**
2. ไอคอนเฟือง ⚙️ → **Web app**
3. ตั้งค่า:
   - **Execute as:** Me (อีเมลคุณ)
   - **Who has access:** **Anyone**
4. **Deploy** → คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

> ทุกครั้งที่แก้ `Code.gs` ต้องกด **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** เพื่อให้มีผล

### 4) ใส่ URL ในหน้าเว็บ
เปิด `eval.html` และ `admin.html` แก้ค่าด้านบนของ `<script>`:

ใน **ทั้งสองไฟล์**:
```js
var API_URL = "วาง Web app URL ที่ได้ตรงนี้";   // .../exec
```
เพิ่มใน **admin.html**:
```js
var EVAL_BASE_URL = "https://USERNAME.github.io/REPO/eval.html"; // ที่ที่โฮสต์ eval.html
```

### 5) โฮสต์ไฟล์ HTML (ฟรี)
ตัวเลือกง่ายสุดคือ **GitHub Pages**:
1. สร้าง repo บน GitHub → อัปโหลด `eval.html` และ `admin.html`
2. Settings → Pages → Branch: `main` / root → Save
3. รอสักครู่จะได้ลิงก์ เช่น `https://USERNAME.github.io/REPO/eval.html`

(หรือใช้ Netlify / Cloudflare Pages / Vercel ก็ได้ — เป็นไฟล์ static ธรรมดา)

### 6) (ทางเลือก) ทำเป็น LIFF ใน LINE OA
ถ้าต้องการให้เปิดในแอป LINE เนียน ๆ:
1. [LINE Developers Console](https://developers.line.biz) → Provider → ช่อง LINE Login channel → แท็บ **LIFF** → Add
2. **Endpoint URL** = ลิงก์ `admin.html` (สำหรับแอดมิน) หรือทำ LIFF แยกชี้ไป `eval.html`
3. ได้ลิงก์ `https://liff.line.me/xxxx` ไปแปะใน Rich Menu / ตอบกลับอัตโนมัติได้เลย

## การใช้งานประจำวัน
- เปิด `admin.html` → ใส่รหัส Admin → แท็บ **สร้างลิงก์**: พิมพ์ชื่อพนักงาน เลือก "ใช้ครั้งเดียว" ระบุจำนวน → ได้ลิงก์ + QR พร้อมแจก
- แท็บ **สถิติ**: ดูคะแนนเฉลี่ย กราฟ การกระจายดาว รายพนักงาน และ **รายการน่าสงสัย** ที่ระบบติดธงไว้

## ปรับแต่งเพิ่มเติม (ใน `Code.gs` → CONFIG)
- `TOKEN_EXPIRY_HOURS` — อายุลิงก์
- `MIN_SECONDS_ON_PAGE` — เวลาขั้นต่ำก่อนกดส่ง
- `MAX_PER_DEVICE_PER_DAY` — โหมดลิงก์เปิด: กี่ครั้ง/อุปกรณ์/วัน
- `DAILY_FLAG_THRESHOLD` — เกินกี่ครั้ง/วัน ถึงติดธงผิดปกติ
- `ALLOW_OPEN_LINK` — ตั้ง `false` เพื่อรับเฉพาะลิงก์ใช้ครั้งเดียว (กันปั้มเข้มสุด)

## ข้อจำกัดที่ควรรู้
- Google Apps Script **ไม่เห็น IP จริง** ของผู้ใช้ จึงใช้ "ลายนิ้วมืออุปกรณ์" แทน (เลี่ยงได้ด้วยการล้างเบราว์เซอร์/เปลี่ยนเครื่อง) — ดังนั้น **ลิงก์ใช้ครั้งเดียว** จึงเป็นเกราะหลัก
- ถ้าต้องการกันโกงระดับสูงสุด แนะนำเพิ่ม LINE Login (LIFF) ภายหลัง เพื่อผูกบัญชี LINE 1 คน = 1 การประเมิน
